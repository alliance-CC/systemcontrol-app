# FAQ テンプレート（コピーして使ってください）

現場サポートモードは、`knowledge/` の中の Markdown を**見出し単位**で検索します。
つまり、**見出しが現場の言葉になっているほど当たります**。

## 使い方

1. このファイルをコピーして、`knowledge/<ツール名>/FAQ.md` として置く。
   例：`knowledge/請求書ツール/FAQ.md`
2. `<ツール名>` を実際の名前に置き換え、5 問だけ埋める（全部埋めなくてよい）。
3. コミットしてデプロイ。画面右の「資料を再読み込み」で即反映されます。

## 書き方のルール（これだけ守れば当たります）

- **見出しは質問そのままの言葉で**。「ログイン手順」より「ログインできない」。
  現場は「認証エラーの解決方法」とは検索しません。「入れない」「開かない」と書きます。
- **1 見出し 1 質問**。長い節に複数の答えを入れると、関係ない部分まで引用されます。
- 手順は**番号付き**で、画面に出ているボタン名をそのまま書く（「保存」「共有」など）。
- **パスワードや API キーの実値は絶対に書かない**。「システムの詳細ページで確認」と誘導する。
- 迷ったら、実際に来た質問を見出しにする（管理者は `/support/logs` で「資料に当たらなかった質問」を確認できます）。

---

以下をコピーして使ってください。

```markdown
# <ツール名> よくある質問

## <ツール名> にログインできない

1. 管理者から届いた URL を開きます。
2. ID とパスワードは、ツール管理システムの詳細ページで確認できます（パスワードは「クリックして表示」）。
3. それでも入れないときは、下の「連絡先」に連絡してください。

## パスワードがわからない

ツール管理システムで <ツール名> を検索し、詳細ページの「パスワード」を「クリックして表示」で確認できます。
表示されない場合は権限がないので、管理者に依頼してください。

## <よくある操作 1>（例：請求書を発行する）

1. 
2. 
3. 

## エラーが出た・画面が真っ白になる

1. いったんページを再読み込みします。
2. それでも直らないときは、**何をしたらどうなったか**をメモしてください。
3. 現場サポートモードの「開発者へ依頼する」から依頼文を作成してください。

## 新しいメンバーを追加したい

<誰に頼むか、どの画面から追加するかを書く。現場が自分でやってよいのか、管理者に頼むのかを必ず明記する。>

## 連絡先

- 平日日中：<担当者・チャンネル名>
- 業務が止まっている場合：<緊急連絡先>
```
