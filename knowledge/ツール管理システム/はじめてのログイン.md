# ツール管理システム はじめてのログイン

社内で使っているツールの ID・パスワードを、まとめて確認できるシステムです。

## ログインする

1. 管理者から届いた URL を開きます。
2. 「ログインID」に、管理者から伝えられた ID を入力します。
3. 「パスワード」を入力して、青い「ログイン」ボタンを押します。
4. システム一覧の画面が表示されたらログイン完了です。

## ログインできないとき

- **「ログインIDまたはパスワードが違います。」と出る**
  入力の間違いか、まだアカウントが作られていない可能性があります。管理者に「アカウントを作ってほしい」と依頼してください。
- **「試行回数が多すぎます」と出る**
  安全のため、一定回数間違えると 10 分間ロックされます。10 分待ってからもう一度お試しください。
- **画面が真っ白になる／エラーが出る**
  システム側の不具合の可能性があります。現場サポートモードから開発者への依頼文を作成してください。

## ログアウト

画面の右上にある「ログアウト」を押します。共有パソコンを使ったときは必ず押してください。
