# 🟢🔴🟡⚪ マークの意味と、困ったときの連絡先

## 一覧に出るマークの意味

- 🟢 **稼働中**：ツールは正常に動いています。
- 🔴 **エラー / 停止**：ツールにつながりません。業務に影響が出ている可能性があります。
- 🟡 **要確認**：つながってはいるものの、判断が難しい状態です（ログインが必要なページなど）。すぐに異常とは限りません。
- ⚪ **監視対象外**：そもそも監視の設定をしていないツールです。

カードの右上に赤い「要対応」バッジが出ているときは、そのシステムのどれかが 🔴 になっています。

## 🔴 が出ていたら

1. まず、そのツール自体を開いてみて、本当に使えないか確認します。
2. 使えない場合は、**現場サポートモード**（上のメニュー「現場サポート」）で質問してください。
3. 解決しない場合は、その画面の「開発者への依頼文を作る」から依頼文を作成し、開発チームに送ってください。

## 新しいツールを登録したい

上のメニューの「新規登録」から登録できます。ツール名（小項目）を選ぶと、そのツールに必要な入力項目が自動で表示されます。
パスワード欄に入れた値は暗号化されて保存されるので、シートを直接見られても中身は読めません。

## 連絡先

- ツールの使い方がわからない → 現場サポートモードで質問
- システムの不具合・改修の相談 → 現場サポートモードで依頼文を作成 → 開発チームへ
